快速开始

1. 一个场景

根节点是 <scene>，grid 把画布划成格子，位置都以格子为单位。


            

            

              
2. 写下步骤

              
每个 <step> 里写“让谁变成什么样”，已有对象把 id 当标签写。同一步里的内容同时发生，步与步依次执行。

              

            

            

              
3. 套一行配色

              
在 <scene> 上写 palette，背景、默认图形色、文字与线条色自动跟随。

              

            

          

        


        

          
常用配方

          
把下面的片段放进 <step> 或 <scene> 就能用，id、坐标按需替换。

          

        


        

          
配色模板

          
语义色 accent accent2 text sub bg bg2 warn good bad 可直接写进 fill、stroke；表达式里用 pal(i) 按序号循环取系列色 c1~c8。

          

        


        

          
地图与旅行路线

          
内置中国地图（省界、外轮廓、南海诸岛）和 380 多个城市的坐标，离线可用，不需要任何外部服务。先写 <map>，之后的对象用 city="成都" 或 lonlat="104.06,30.66" 定位，path="北京 武汉 广州" 一句话走完整条路线。

          

          
线条样式：每一组都能自己定

          

          
内置交通工具图标

          

          
说明：城市坐标取自行政中心点，精度到城市级别；冷门地点请直接写 lonlat（经度在前）。地图不含街道，公路段用直线或 arc 弧线表示。

        


        

          
字幕样式

          
默认字幕是安静的半透明胶囊，颜色跟随配色。在 <scene> 上写 caption 换样式，caption-size 调字号，caption-pos 放到上方；编辑器里也有对应的下拉框。下面的预览为了看清，统一用了 large 字号。

          

          

        


        

          
缓动速查

          
在任何会动的属性上写 ease="名字"；不写则按引擎默认。同一个动作换缓动，手感完全不同。
