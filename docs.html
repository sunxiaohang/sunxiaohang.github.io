快速开始

1. 一个场景

根节点是 <scene>，grid 把画布划成格子，位置都以格子为单位。


            

            

              
2. 写下步骤

              
每个 <step> 里写“让谁变成什么样”，已有对象把 id 当标签写。同一步里的内容同时发生，步与步依次执行。

              

            

            

              
3. 套一行配色

              
在 <scene> 上写 palette，背景、默认图形色、文字与线条色自动跟随。

              

            

          

        


        

          
常用配方

          
把下面的片段放进 <step> 或 <scene> 就能用，id、坐标按需替换。

          

        


        

          
配色模板

          
语义色 accent accent2 text sub bg bg2 warn good bad 可直接写进 fill、stroke；表达式里用 pal(i) 按序号循环取系列色 c1~c8。

          

        


        

          
缓动速查

          
在任何会动的属性上写 ease="名字"；不写则按引擎默认。同一个动作换缓动，手感完全不同。
